# 机器流转规划同步脚本需求文档

## 功能概述

同步脚本从4个确认执行Sheet读取KOL达人数据，筛选后同步到"机器流转规划"Sheet，并更新相关状态信息。

## 核心功能

### 1. 数据同步

**数据来源** (4个确认执行Sheet):
- 小红书确认执行3月 (Sheet ID: ZzaIyS)
- 小红书确认执行4月 (Sheet ID: TDxBlT)
- 3月抖音确认执行 (Sheet ID: f08bd2)
- 4月抖音确认执行 (Sheet ID: iFO2b6)

**目标Sheet** (机器流转规划):
- 机器流转规划3月 (Sheet ID: 98jnHp)
- 机器流转规划4月 (Sheet ID: FkznaW)

**写入字段**:
- 平台 (小红书/抖音)
- 博主 (昵称)
- 燃气类型 (气源)
- 地址/收件人/联系电话 (产品邮寄地址)
- 发布时间 (从确认执行Sheet的"发布时间"列获取，无数据显示"未知")

**筛选条件**:
1. 达人量级包含"KOL" (不包含KOC)
2. 产品邮寄地址不包含"抠图"

**去重逻辑**: 博主昵称已存在于目标表则跳过

### 2. 更新已发布状态

根据源表的"发布状态"列，将"已发布"的博主在目标表的"是否已发布"列标记为"是"。

**更新逻辑**: 如果目标表中已有内容和本次计算的内容不一致才更新，以本次计算内容为准。

### 3. 更新KOC/KOL抠图状态

**KOC达人** (达人量级包含KOC):
- 产品邮寄地址: 无需收集
- 气源: 无需收集
- 产品快递状态: 无需配送产品
- 样机情况: 无样机

**KOL但地址包含"抠图"**:
- 气源: 无需收集
- 产品快递状态: 无需配送产品
- 样机情况: 无样机

### 4. 更新发布时间

**数据来源**: 从确认执行Sheet的"发布时间"列获取

**更新逻辑**: 每次执行脚本遍历目标表所有行，如果目标表中已有内容和本次计算的内容不一致才更新，以本次计算内容为准。无数据显示"未知"。

### 5. 更新流转沟通情况

**更新逻辑**: 每次执行脚本遍历目标表所有行，如果流转沟通情况列内容为空才更新。

**触发条件** (满足任一条件):
1. 发布时间距今小于10天且流转沟通情况列为空 → 标记"需安排流转机器"，字体标红
2. 同时满足以下条件 → 标记"需沟通寄走机器"，字体标红:
   - 是否已发布 = 是
   - 是否需要寄走机器 = 是
   - 流转沟通情况 = 空
   - 流转单号（接收）有数据
   - 流转单号（寄出）= 空

### 6. 更新确认执行表的"是否修改"列

**触发条件**: KOL且地址非抠图的数据

**更新内容**: 在确认执行表的"是否修改"列标记为"是"

## 命令行参数

```
python sync_machine_plan.py <小红书3月起始行> <小红书4月起始行> <抖音3月起始行> <抖音4月起始行> [是否更新已发布:0或1] [是否更新KOC状态:0或1] [是否更新确认执行表:0或1]
```

**示例**:
```
python sync_machine_plan.py 3 5 2 8 1 1 1
```

**参数说明**:
- 前4个参数: 各Sheet的数据起始行号
- 第5个参数 (可选): 是否更新已发布状态，默认1 (是)
- 第6个参数 (可选): 是否更新KOC/KOL抠图状态，默认1 (是)
- 第7个参数 (可选): 是否更新确认执行表的"是否修改"列，默认1 (是)

## 使用场景

1. 每月定期同步确认执行数据到机器流转规划表

5. 提醒需沟通寄走机器的达人 (已发布+需寄走+有接收单号无寄出单号)
