# 机器流转规划同步脚本需求文档

## 功能概述

同步脚本分为4个独立任务，可通过命令行参数选择性执行。

---

**目标Sheet**:
- 小红书确认执行4月 (Sheet ID: TDxBlT)
- 小红书确认执行5月 (Sheet ID: OJdYYD)

**数据来源**: 
- 小红书二核表 (Sheet ID: 2kiAq6)

**字段映射**:
| 目标列名 | 源列名 |
|---------|--------|
| 昵称 | 昵称 |
| ID | ID |
| 主页链接 | 主页链接 |
| 合作形式 | 合作形式 |
| 平台价（平台裸价） | 平台价格 |

**更新规则**:
- 如果目标单元格已有数据，不执行更新（保护已有数据）
- 按昵称匹配行

## 任务3: 更新小红书机器流转sheet

**数据流向**: 小红书确认执行表 → 机器流转规划表

**数据来源**:
- 小红书确认执行3月 (Sheet ID: ZzaIyS)
- 小红书确认执行4月 (Sheet ID: TDxBlT)

**目标Sheet**:
- 机器流转规划3月 (Sheet ID: 98jnHp)
- 机器流转规划4月 (Sheet ID: FkznaW)

**写入字段**:
- 平台: 小红书
- 博主: 昵称
- 燃气类型: 气源
- 地址/收件人/联系电话: 产品邮寄地址
- 发布时间: 发布时间（无数据显示"未知"）

**筛选条件**:
1. 达人量级包含"KOL"（不包含KOC）
2. 产品邮寄地址不包含"抠图"

**去重逻辑**: 博主昵称已存在于目标表则跳过

**附加更新**:
1. **更新已发布状态**: 根据源表的"发布状态"列，将"已发布"的博主在目标表的"是否已发布"列标记为"是"
2. **更新KOC/KOL抠图状态**:
   - KOC达人: 产品邮寄地址=无需收集, 气源=无需收集, 产品快递状态=无需配送产品, 样机情况=无样机
   - KOL但地址包含"抠图": 气源=无需收集, 产品快递状态=无需配送产品, 样机情况=无样机
3. **更新发布时间**: 每次执行脚本遍历目标表所有行，如果目标表中已有内容和本次计算的内容不一致才更新
4. **更新流转沟通情况**:
   - 发布时间距今小于10天且流转沟通情况列为空 → 标记"需安排流转机器"，字体标红
   - 已发布+需寄走+有接收单号无寄出单号 → 标记"需沟通寄走机器"，字体标红

## 命令行参数

```
python sync_machine_plan.py <小红书3月起始行> <小红书4月起始行> <抖音3月起始行> <抖音4月起始行> [任务开关]
```

**示例**:
```
python sync_machine_plan.py 3 5 2 8 1 1 1 1
```

**参数说明**:
- 前4个参数: 各Sheet的数据起始行号
- 第5个参数 (可选): 是否执行任务1（更新小红书确认执行sheet），默认1 (是)
- 第6个参数 (可选): 是否执行任务2（更新抖音确认执行sheet），默认1 (是)
- 第7个参数 (可选): 是否执行任务3（更新小红书机器流转sheet），默认1 (是)
- 第8个参数 (可选): 是否执行任务4（更新抖音机器流转sheet），默认1 (是)
